Risk architecture

Capital protection is
enforced in code.

Every control below is a hard stop in the execution path, not a guideline a human is trusted to follow.

Enforced in code

Consecutive-loss circuit breaker

Trading halts automatically after three consecutive losses on an account. Resuming requires deliberate human action — the system will not quietly restart itself.

Enforced in code

Daily loss ceiling

A 3% daily drawdown on an account closes the door for that day, independent of how many setups qualify afterwards.

Enforced in code

Fixed position sizing

Live sizing is pinned to a fixed lot rather than scaled by conviction. Sizing was the source of a historical 74× oversize defect, and it is deliberately kept boring.

Enforced in code

Stale-source refusal

If a signal was computed from a different instrument's price feed than the one being traded, the bridge refuses the order outright rather than trading the wrong levels.

Enforced in code

Concurrent position cap

A hard ceiling on simultaneously open positions, checked at order time, so a burst of qualifying signals cannot compound into concentrated exposure.

Enforced in code

Broker-side stops

Every position carries a stop loss held at the broker, so protection survives a crash, a restart or a network partition on our side.

Limits

What we won't claim.

The fastest way to judge a trading system is by what its marketing refuses to say. Here is ours, in writing.

  • No projected or target returns. We will not publish a percentage we have not earned, and we do not have one to publish.
  • No backtested equity curve presented as performance. A curve fitted in hindsight is a drawing, not a result.
  • No Sharpe, CAGR or max-drawdown figures. All three are undefined at this sample size, and quoting them would be arithmetic theatre.
  • No win rate computed from a handful of trades. The page suppresses its own win rate below the stated threshold, even when that rate would flatter us.
  • No testimonials or client results. There are no clients. Inventing either would be fraud, not marketing.
  • No claim that live results will resemble any test. Out-of-sample testing reduces self-deception; it does not predict the future.
  • No suggestion this is safe. Algorithmic trading can lose money faster than manual trading, precisely because it does not hesitate.
