SmartEntry Pro runs on Node.js + Express on port 3001. Python mt5_bridge.py connects to MetaTrader 5 via the MetaTrader5 Python package. Claude Opus (claude-opus-4-8) approves every trade. Signals fire only when confidence >= 65% across Daily + 4H + 1H timeframes. Yahoo Finance v8 API for Gold/SPY/DXY/VIX candles. CoinGecko for BTC live price. Multi-timeframe signals use parallel Promise.all for refresh. MT5 bridge uses ThreadPoolExecutor for parallel BTC+Gold processing.
