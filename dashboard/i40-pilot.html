i40 Pilot

This system scored against the acatech Industrie 4.0 Maturity Index, and every pilot asked the one question that defines a pilot: has it transcended to a full project?

Six stages, each answering one question, each building on the last. RAMI 4.0 is deliberately not used here — its hierarchy axis is the factory floor (field device, control device, station, work centre) and there is no honest mapping from a trading system onto a work centre. The acatech index is a capability model, which is why it fits. Every verdict below is computed from live endpoints, never asserted. Nothing here feeds the gate.

PILOT-001 — the registered pilot

A pilot is a scoped experiment, not a dashboard. Its four measurements were fixed before it started, which is the only thing that stops anyone finding the metric afterwards that makes it look successful. Nothing in the charter may be edited while it runs; a wrong criterion kills the pilot and starts PILOT-002 with a new baseline.

Pilots — has it transcended to a full project?

The success criterion for a pilot is that it transcends. For this system that means one thing: has the model been trusted with real money, or is it still paper? A model with a shadow ledger and no fills has not transcended, however good the paper looks.
