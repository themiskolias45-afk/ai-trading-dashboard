Continuous learning — the loop that closes back to the start

Every fill lands in the journal with its realised R. Every gate REJECTION is priced as a paper trade on real broker bars, so the system learns from setups it never took as well as the ones it did. Calibration asks whether 85% confidence really produced 85% wins. None of it feeds the gate: every evidence surface returns feedsTheGate:false, which is enforced in code, so measuring can never quietly change what trades.

Solid panels are bound to live endpoints. Dashed and greyed items are planned, not built — drawn so the ambition stays visible without being asserted as fact. A value of ? means the reading could not be taken, never that it is healthy.
