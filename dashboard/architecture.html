The trade path
top to bottom — a bar arrives, an order fills
Each stage carries its own live state. A green edge means that stage is working right now; red means it is not; grey means nothing has exercised it yet, which is not the same thing as healthy. The line between two stages says what physically moves, and over what.
The fleet

A number that pools both boxes is unattributable while their settings or engines differ, so nothing here is merged. Rows the server flags as differing are marked red; rows that differ by design — per-machine on purpose — are amber and are not a fault.
The ten gates
Counts reset when the server restarts, so a row of zeros usually means "not exercised this uptime", not "broken". Six of these read silent for reasons that are correct by design, and the WHY column says which. None of the ten is known to be broken — do not "fix" a quiet one.
